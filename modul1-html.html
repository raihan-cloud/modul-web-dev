🧱 Modul 1: Semantik & Aksesibilitas HTML5

Penguasaan Standar HTML5 Industry-Ready: Struktur SEO, Aksesibilitas Web (a11y), Validasi Form Tanpa JS, dan Optimasi Media.

💡 Filosofi HTML Modern: Lebih Dari Sekadar Tampilan Di industri web profesional, HTML dibaca oleh tiga entitas: Pengguna (visual), Mesin Pencari / Google (SEO), dan Screen Reader (Aksesibilitas penyandang disabilitas). Penggunaan tag pembungkus biasa seperti <div> untuk segalanya (*Div Soup*) adalah praktik buruk yang harus dihindari.

1.1 Struktur Semantik & SEO Optimization

Elemen semantik memberikan arti jelas pada struktur web sehingga mesin pencari seperti Google dapat dengan mudah memahami tata letak dan hierarki konten utama Anda.

<header>
  <nav>
    <a href="/">Beranda</a>
  </nav>
</header>

<main>
  <article>
    <h1>Panduan HTML5 Modern</h1>
    <section>
      <h2>Sub-materi 1</h2>
      <p>Konten artikel...</p>
    </section>
  </article>

  <aside>
    <p>Widget/Rekomendasi Berita</p>
  </aside>
</main>

<footer>
  <p>&copy; 2026 Hak Cipta Dilindungi.</p>
</footer>
Fungsi Tag Semantik Utama:
  • <header>: Mewakili area navigasi, logo, atau tajuk teratas.
  • <main>: Tempat konten unik utama. Wajib hanya ada 1 per halaman.
  • <article>: Konten mandiri yang bisa berdiri sendiri (misal: postingan blog, produk).
  • <section>: Kelompok konten yang memiliki topik/heading khusus dalam artikel.
  • <aside>: Konten pendamping seperti sidebar, iklan, atau rekomendasi.

1.2 Aksesibilitas (a11y) & ARIA Attributes

Aksesibilitas memastikan website dapat digunakan oleh penyandang tunanetra atau pengguna yang bernavigasi tanpa mouse (menggunakan Keyboard Tab).

<!-- Tombol dengan ikon tanpa teks wajib menggunakan aria-label -->
<button aria-label="Tutup Mode Gelap" class="btn-icon">
  <span>&times;</span>
</button>

<!-- Memberikan penjelasan state pada menu dropdown/akordeon -->
<button aria-expanded="false" aria-controls="menu-list">
  Buka Menu
</button>

<!-- Gambar deklaratif wajib alt, gambar dekoratif diberi alt kosong -->
<img src="user.jpg" alt="Foto profil Raihan Muzaffar">
<img src="divider.png" alt="" aria-hidden="true">

1.3 Form & Validasi Bawaan (Tanpa JavaScript)

HTML5 menyediakan sistem validasi input canggih menggunakan atribut seperti required, pattern (Regex), dan penentuan tipe spesifik.

<form>
  <!-- Validasi Format Email Asli -->
  <label for="email">Email Kantor:</label>
  <input type="email" id="email" required placeholder="nama@perusahaan.com">

  <!-- Validasi Regex: Minimal 8 Karakter (Ada Angka & Huruf Besar) -->
  <label for="pass">Password:</label>
  <input type="password" id="pass" required 
         pattern="(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}"
         title="Minimal 8 karakter, wajib memuat angka, huruf besar & kecil">

  <button type="submit">Daftar Akun</button>
</form>

1.4 Optimasi Media & Lazy Loading

Mempercepat performa loading website (Core Web Vitals) dengan penyajian gambar responsif via elemen <picture> dan atribut loading="lazy".

<!-- 1. Lazy loading otomatis menunda download gambar sebelum di-scroll -->
<img src="banner.webp" alt="Banner Modul" loading="lazy" width="800" height="400">

<!-- 2. Elemen Picture untuk menyajikan format ringan WebP/AVIF sesuai browser -->
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Hero Banner" loading="eager">
</picture>
Mengapa atribut width & height penting? Menentukan atribut `width` dan `height` pada tag gambar akan mencegah terjadinya loncatan tata letak (*Cumulative Layout Shift / CLS*) saat halaman sedang dimuat.

1.5 Open Graph & Social Media Meta Tags

Protokol Open Graph digunakan agar tautan website kamu menampilkan kartu pratinjau yang indah saat dibagikan ke WhatsApp, LinkedIn, X (Twitter), atau Facebook.

<head>
  <!-- Open Graph Basic -->
  <meta property="og:title" content="Modul Belajar Web Development Modern">
  <meta property="og:description" content="Kuasai HTML5, CSS3, dan JS dari Nol Berdasarkan Standar Industri.">
  <meta property="og:image" content="https://website.com/assets/og-preview.jpg">
  <meta property="og:url" content="https://website.com/modul">
  <meta property="og:type" content="website">

  <!-- Twitter Card -->
  <meta name="twitter:card" content="summary_large_image">
</head>

1.6 Data Attributes (`data-*`)

Data Attributes memungkinkan kamu menyimpan data kustom pada elemen HTML secara valid tanpa mengganggu tampilan, yang kemudian dapat diproses oleh CSS atau JavaScript.

<!-- Menyimpan metadata kustom pada elemen -->
<div class="user-card" data-user-id="1082" data-role="admin" data-status="active">
  <h3>Raihan Muzaffar</h3>
</div>

<!-- CSS dapat mengambil nilai atribut ini -->
<style>
  .user-card[data-status="active"]::after {
    content: " • " attr(data-role);
    color: #22c55e;
    font-weight: bold;
  }
</style>

🎯 Latihan Praktikum Industry-Grade

Buatlah satu file HTML baru bernama portofolio-aksesibel.html dengan ketentuan standar berikut:

  1. Gunakan struktur semantik utuh (minimal memuat <header>, <nav>, <main>, <article>, dan <footer>).
  2. Sematkan meta tag Open Graph lengkap pada bagian <head>.
  3. Buat formulir kontak yang memiliki atribut validasi regex pattern dan required untuk nomor telepon/email.
  4. Gunakan atribut loading="lazy" serta alternatif deskripsi alt yang aksesibel pada seluruh gambar.
  5. Tambahkan atribut data-category pada kartu daftar proyek kamu.
