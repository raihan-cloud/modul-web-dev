🧱 Modul 1: Dasar & Struktur HTML5

Selamat datang di dunia Web Development! Di modul ini, kita akan mempelajari cara menyusun fondasi sebuah halaman web menggunakan elemen-elemen standar HTML5.

💡 Konsep Dasar: Apa itu HTML? Bayangkan kamu sedang membangun sebuah rumah. HTML (HyperText Markup Language) adalah batu bata, tiang, dan kerangkanya. HTML bertugas menentukan struktur website: mana yang menjadi judul, paragraf, gambar, maupun tombol.

1.1 Struktur Wajib HTML (Boilerplate)

Setiap dokumen HTML wajib memiliki struktur dasar yang disebut boilerplate. Tanpa struktur ini, browser tidak dapat menampilkan halaman dengan benar.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Halaman Pertama Saya</title>
</head>
<body>
  <h1>Halo Dunia!</h1>
</body>
</html>
Bedah Kode (Baris per Baris):
  • <!DOCTYPE html>: Memberitahu browser bahwa ini dokumen HTML5.
  • <html lang="id">: Pembungkus utama dokumen berpemasok bahasa Indonesia.
  • <head>: Tempat pengaturan web (meta tag, judul tab, CSS) yang tidak muncul di area baca.
  • <meta charset="UTF-8">: Memastikan dukungan standar karakter dan emoji.
  • <meta name="viewport"...>: Mengatur responsivitas halaman di layar mobile.
  • <body>: Tempat seluruh konten visual (teks, gambar, link) diletakkan.

1.2 Teks & Format (Heading & Paragraf)

Untuk menulis teks, gunakan tag yang sesuai agar browser memahami hierarki informasi pada halaman web Anda.

A. Heading (Judul)

Tersedia 6 tingkatan judul, mulai dari <h1> (terbesar/terpenting) hingga <h6> (terkecil).

B. Paragraf & Format Teks

Gunakan <p> untuk paragraf, <strong> untuk penekanan tebal, dan <em> untuk cetak miring.

<h1>Belajar HTML itu Menyenangkan</h1>
<h2>Bab 1: Pengenalan</h2>

<p>Ini adalah paragraf. Kamu bisa menggunakan kata <strong>tebal</strong> 
atau kata <em>miring</em> di dalamnya.</p>

<p>Jika ingin pindah baris tanpa membuat paragraf baru,<br> 
gunakan tag br (line break).</p>
👁️ Hasil Tampilan Browser:

Belajar HTML itu Menyenangkan

Bab 1: Pengenalan

Ini adalah paragraf. Kamu bisa menggunakan kata tebal atau kata miring di dalamnya.

Jika ingin pindah baris tanpa membuat paragraf baru,
gunakan tag br (line break).

1.3 Menambahkan Link & Gambar

Membuat elemen interaktif dengan tautan dan media visual:

A. Tautan / Link (<a>)

Tag Anchor membutuhkan atribut href yang berisi URL tujuan.

B. Gambar (<img>)

Tag ini tidak memerlukan tag penutup. Membutuhkan atribut src (path/URL gambar) dan alt (deskripsi gambar).

<!-- Link yang akan terbuka di tab baru -->
<a href="https://google.com" target="_blank">Buka Google</a>

<!-- Menampilkan Gambar -->
<img src="https://via.placeholder.com/150" alt="Foto Profil Saya">
Tips Penting: Gunakan atribut target="_blank" pada tautan eksternal agar pengguna tidak meninggalkan halaman web utama Anda saat menguklik tautan tersebut.

1.4 Membuat Daftar (List)

Daftar dapat disusun secara berurutan (*Ordered List*) atau tidak berurutan (*Unordered List*).

<h3>Daftar Belanja (Unordered List):</h3>
<ul>
  <li>Beras</li>
  <li>Telur</li>
</ul>

<h3>Cara Memasak Telur (Ordered List):</h3>
<ol>
  <li>Nyalakan kompor</li>
  <li>Pecahkan telur ke wajan</li>
</ol>
👁️ Hasil Tampilan Browser:

Daftar Belanja (Unordered List):

  • Beras
  • Telur

Cara Memasak Telur (Ordered List):

  1. Nyalakan kompor
  2. Pecahkan telur ke wajan

1.5 Formulir (Form Input)

Formulir digunakan untuk menangkap masukan (*input*) dari pengguna.

<form>
  <label for="nama">Nama Lengkap:</label>
  <input type="text" id="nama" placeholder="Tulis nama kamu...">

  <label for="email">Alamat Email:</label>
  <input type="email" id="email" placeholder="contoh@mail.com">

  <button type="submit">Daftar Sekarang</button>
</form>

1.6 Elemen Semantik HTML5

Penggunaan elemen semantik memberikan konteks bermakna pada struktur web:

  • <header> : Menampung logo, tajuk, atau menu navigasi atas.
  • <nav> : Menampung daftar tautan navigasi utama.
  • <main> : Menampung konten utama halaman web.
  • <footer> : Bagian catatan kaki, hak cipta, atau tautan tambahan.

🎯 Latihan Mandiri

Praktikkan materi yang telah dipelajari dengan membuat file baru bernama biodata.html:

  1. Buat struktur dasar HTML5 (boilerplate).
  2. Gunakan <h1> untuk judul nama lengkap Anda.
  3. Tampilkan foto profil menggunakan tag <img>.
  4. Tulis paragraf <p> singkat tentang hobi Anda (sertakan format <strong>).
  5. Buat daftar <ul> berisi 3 keahlian atau makanan favorit.
  6. Tambahkan tautan <a> ke akun media sosial atau portofolio Anda.
