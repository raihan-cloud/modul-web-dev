⚡ Modul 3: Dasar & Interaktivitas JavaScript

Memberikan logika, merespons tindakan pengguna, serta memanipulasi elemen halaman web secara real-time menggunakan JavaScript Vanilla.

💡 Konsep Dasar: Apa peran JavaScript? Jika HTML adalah struktur rumah dan CSS adalah dekorasinya, maka **JavaScript** adalah **sistem kelistrikan dan otomatisasinya**: tombol lampu yang menyala saat ditekan, pintu otomatis yang terbuka saat didekati, hingga bel pintu yang berbunyi.

3.1 Menghubungkan JavaScript ke HTML

Sama seperti CSS, kode JavaScript dapat diletakkan di dalam file HTML atau dipisahkan ke dalam file eksternal berekstensi .js.

1. External JavaScript (Sangat Direkomendasikan)

Menuliskan kode pada file terpisah bernama script.js, lalu memanggilnya sebelum tag penutup </body>.

<!-- Di bagian bawah file index.html -->
  <script src="script.js"></script>
</body>
Mengapa di Bawah? Meletakkan tag <script> di akhir elemen <body> memastikan seluruh elemen HTML telah selesai di-load oleh browser sebelum JavaScript mencoba memanipulasinya.

3.2 Variabel & Tipe Data Dasar

Variabel digunakan untuk menyimpan data dalam memori program. Di JavaScript modern (ES6+), kita menggunakan let dan const.

  • const: Digunakan untuk nilai tetap yang tidak akan diubah nilainya.
  • let: Digunakan untuk variabel yang nilainya dapat berubah.
// Contoh Variabel dan Tipe Data
const namaWebsite = "Portfolio Saya"; // String
let jumlahPengunjung = 150;           // Number
let isOnline = true;                  // Boolean

// Mengubah nilai variabel let
jumlahPengunjung = jumlahPengunjung + 1;

3.3 Manipulasi DOM (Document Object Model)

DOM memungkinkan JavaScript membaca dan mengubah struktur, teks, maupun gaya CSS dari halaman HTML secara langsung saat program berjalan.

// 1. Mengambil elemen berdasarkan ID
const teksTarget = document.getElementById("teks-demo");

// 2. Mengubah isi teks
teksTarget.textContent = "Halo! Teks ini diubah oleh JavaScript!";

// 3. Mengubah gaya CSS
teksTarget.style.color = "#059669";

3.4 Event Handling (Merespons Interaksi)

Event adalah peristiwa yang terjadi di browser, seperti klik mouse, pengetikan keyboard, atau saat form dikirim (*submit*). Kita menggunakan addEventListener() untuk meresponsnya.

const tombol = document.querySelector("#tombol-klik");

// Mendengarkan kejadian 'click'
tombol.addEventListener("click", function() {
  alert("Tombol berhasil diklik!");
});
