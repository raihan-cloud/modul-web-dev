⚡ Modul 3: Modern Vanilla JavaScript (ES6+)

Menguasai Logika Web, Manipulasi DOM Modern, Event Delegation, Asynchronous Data Fetching, dan State Persistence.

💡 Paradigma JavaScript Industri Modern JavaScript bukan sekadar script untuk efek animasi sederhana. Pada arsitektur web modern, JavaScript Vanilla (ES6+) berfungsi sebagai **engine logika utama** yang mengelola status (*state*), berkomunikasi dengan Server API secara asynchronous, dan mengubah tampilan DOM tanpa perlu memuat ulang seluruh halaman (*Single Page App Experience*).

3.1 Loading Strategy Modern & ES6 Modules

Penggunaan atribut defer atau type="module" merupakan standar wajib untuk memuat file JavaScript tanpa menghentikan proses rendering halaman HTML oleh browser.

<!-- Diletakkan di tag <head> dengan atribut defer -->
<script src="app.js" defer></script>

<!-- Menggunakan ES6 Module untuk arsitektur terpisah -->
<script type="module" src="main.js"></script>
Mengapa Menggunakan `defer`? Atribut defer mengunduh file script secara parallel di latar belakang saat HTML di-parse, dan mengeksekusinya secara berurutan tepat setelah struktur DOM siap disajikan.

3.2 Syntax Modern (Shorthand ES6+)

Memanfaatkan fitur modern JavaScript seperti Arrow Functions, Template Literals, dan Destructuring untuk menghasilkan kode yang bersih dan minim *boilerplate*.

// 1. Arrow Function & Template Literals
const sapaUser = (nama, peran = 'Developer') => {
  return `Selamat datang ${nama}, kamu login sebagai ${peran}.`;
};

// 2. Destructuring Object & Array
const config = { theme: 'dark', language: 'id' };
const { theme, language } = config;

3.3 DOM Selection & Class Manipulation

Alih-alih mengubah properti style.color secara langsung (inline style), alur kerja modern merekomendasikan penggunaan classList.add(), remove(), atau toggle() dengan kombinasi class CSS.

const cardElement = document.querySelector('.card-target');

// Mengubah state visual via CSS Class
cardElement.classList.toggle('active-card');

3.5 Asynchronous JS & Fetch API (`async/await`)

Mengambil data external secara *asynchronous* dari server API tanpa perlu memuat ulang (*reload*) halaman web.

const loadData = async () => {
  try {
    const res = await fetch('https://api.github.com/users/octocat');
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error('Gagal mengambil data:', err);
  }
};
