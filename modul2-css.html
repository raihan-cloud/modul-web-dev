🎨 Modul 2: Dasar & Stiling CSS3

Mengubah tampilan halaman HTML polos menjadi menarik, rapi, dan profesional menggunakan CSS3 (Cascading Style Sheets).

💡 Konsep Dasar: Apa itu CSS? Jika HTML adalah kerangka bangunan, maka **CSS (Cascading Style Sheets)** adalah **desain interiornya**: cat dinding, warna perabotan, jenis font, hingga tata letak ruangan. Tanpa CSS, web kamu hanya akan berisi teks polos dan gambar tanpa dekorasi.

2.1 Cara Menghubungkan CSS ke HTML

Ada tiga cara utama untuk menerapkan style CSS ke dalam file HTML:

1. External CSS (Paling Direkomendasikan)

Memisahkan kode CSS di file terpisah bernama style.css, lalu dihubungkan melalui tag <link> di dalam bagian <head>.

<!-- Di dalam file index.html -->
<head>
  <link rel="stylesheet" href="style.css">
</head>

2. Internal CSS

Menuliskan kode CSS di dalam file HTML yang sama dengan membungkusnya menggunakan tag <style> di bagian <head>.

3. Inline CSS

Menuliskan atribut style="" langsung di dalam tag HTML. (Kurang disarankan untuk proyek skala besar).

Best Practice: Selalu gunakan metode **External CSS** agar kode HTML tetap bersih, mudah dibaca, serta file CSS tersebut dapat digunakan ulang (*reusable*) di halaman web lainnya.

2.2 Selectors & Properti Dasar

CSS bekerja dengan pola **Selector** (elemen mana yang ingin diubah) dan **Declaration** (sifat apa yang ingin diatur).

A. Jenis Selector Utama

  • Tag Selector: Memilih semua tag tertentu (misal: p { color: blue; }).
  • Class Selector (.): Memilih elemen dengan nama kelas spesifik (misal: .kartu { background: white; }).
  • ID Selector (#): Memilih satu elemen unik (misal: #header-utama { font-size: 24px; }).
/* Contoh penulisan CSS dasar */
body {
  font-family: 'Segoe UI', sans-serif;
  background-color: #f8fafc;
  color: #0f172a;
}

.judul-utama {
  color: #2563eb;
  font-size: 1.8rem;
  text-align: center;
}

2.3 CSS Box Model

Setiap elemen di HTML dianggap sebagai sebuah "kotak" (*box*). Konsep ini menentukan bagaimana ukuran dan ruang antar elemen dihitung.

📦 Struktur Anatomi Box Model:
MARGIN (Ruang Luar)
BORDER (Garis Tepi)
PADDING (Ruang Dalam)
CONTENT (Teks / Gambar) 
/* Mengatur Box Model elemen kartu */
.card {
  width: 300px;
  padding: 20px;       /* Ruang antara konten & border */
  border: 2px solid #cbd5e1; /* Garis pembatas */
  margin: 15px;        /* Jarak dengan elemen di luarnya */
  box-sizing: border-box; /* Memastikan ukuran tetap konsisten */
}
Tips Penting (box-sizing: border-box): Secara default, menambahkan padding dan border akan menambah total lebar elemen. Menggunakan box-sizing: border-box membuat total lebar elemen tetap sesuai nilai width yang ditentukan.

2.4 Layout Modern dengan Flexbox

Flexbox adalah teknik CSS modern untuk menyusun tata letak elemen secara sejajar (horisontal atau vertikal) dengan mudah dan responsif.

/* Mengaktifkan Flexbox pada kontainer */
.flex-container {
  display: flex;
  justify-content: space-between; /* Meratakan jarak antar kolom */
  align-items: center;            /* Meratakan vertikal di tengah */
  gap: 1rem;                      /* Jarak antar item */
}

2.5 Interaktivitas & State Pseudo-Classes

CSS memungkinkan kita memberikan respons visual saat pengguna berinteraksi dengan elemen, seperti mengarahkan kursor (*hover*) atau mengeklik tombol.

/* Style tombol dasar */
.tombol {
  background-color: #2563eb;
  color: white;
  padding: 10px 20px;
  border-radius: 6px;
  transition: all 0.3s ease; /* Transisi animasi halus */
}

/* Efek saat kursor berada di atas tombol */
.tombol:hover {
  background-color: #1d4ed8;
  transform: translateY(-2px); /* Mengangkat tombol sedikit */
}

🎯 Latihan Mandiri Modul 2

Saatnya menghias file biodata.html yang telah kamu buat di Modul 1!

  1. Buat file CSS baru bernama style.css di folder yang sama dengan biodata.html.
  2. Hubungkan file CSS tersebut menggunakan tag <link rel="stylesheet" href="style.css"> pada bagian <head>.
  3. Atur warna latar belakang halaman (body) dengan warna lembut (misal: #f8fafc).
  4. Bungkus konten biodatamu dalam sebuah kartu (<div class="card">), lalu beri gaya: background-color: white, padding, border-radius, dan box-shadow.
  5. Ubah gaya tombol atau link sosial mediamu agar memiliki efek saat di-hover.
