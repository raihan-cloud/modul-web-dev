🎨 Modul 2: Layout Modern & Arsitektur CSS3

Menguasai Arsitektur CSS Modern: Dark Mode berbasis Variabel, CSS Grid, Fluid Typography, Glassmorphism, dan Metode BEM.

💡 Paradigma CSS Industri Modern CSS bukan sekadar pemberi warna teks, melainkan **sistem desain spasial dan arsitektur visual**. Pembuat web profesional tidak lagi menggunakan trik lama seperti `float` atau menentukan ukuran font manual di puluhan breakpoint `@media`, melainkan memanfaatkan fitur native engine CSS modern.

2.1 CSS Variables & Dark Mode System

Penggunaan Custom Properties (CSS Variables) memungkinkan pengelolaan sistem warna terpusat dan pembuatan fitur Mode Gelap (*Dark Mode*) hanya dalam beberapa baris kode.

:root {
  --bg-primary: #ffffff;
  --text-primary: #0f172a;
  --brand-color: #2563eb;
}

/* Mengubah variabel secara otomatis saat pengguna memilih Mode Gelap */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #0f172a;
    --text-primary: #f8fafc;
  }
}

/* Penerapan variabel pada elemen */
body {
  background-color: var(--bg-primary);
  color: var(--text-primary);
}
Keunggulan CSS Variables: Variabel CSS bersifat dinamis dan mewariskan nilai ke elemen anaknya (*cascading*), berbeda dari variabel pada preprocessor seperti SASS yang bernilai statis setelah di-compile.

2.2 Flexbox vs CSS Grid Mastery

Pahami perbedaan mendasar: **Flexbox** dirancang untuk tata letak 1-Dimensi (baris ATAU kolom), sedangkan **CSS Grid** dirancang untuk tata letak 2-Dimensi (baris DAN kolom sekaligus).

Simulasi Responsive Grid Tanpa Media Queries (`auto-fit`)

/* Kolom otomatis menyesuaikan jumlah & lebar layar tanpa @media */
.dashboard-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(130px, 1fr));
  gap: 1rem;
}

2.3 Fluid Typography dengan `clamp()`

Fungsi `clamp(MIN, VAL, MAX)` memungkinkan ukuran font membesar dan mengecil secara fleksibel menyesuaikan lebar layar monitor tanpa perlu menulis banyak `@media` query.

h1 {
  /* Min: 1.5rem, Fleksibel: 4vw, Max: 3rem */
  font-size: clamp(1.5rem, 4vw, 3rem);
}

2.4 CSS Animations & Glassmorphism UI

Menciptakan antarmuka modern berbahan efek kaca transparan menggunakan `backdrop-filter` dan animasi performa tinggi via `transform` & `opacity`.

.card-glass {
  background: rgba(255, 255, 255, 0.4);
  backdrop-filter: blur(12px); /* Memburamkan latar belakang */
  border: 1px solid rgba(255, 255, 255, 0.5);
  border-radius: 12px;
}

2.5 Container Queries (`@container`)

Teknik responsif masa depan: Jika Media Queries mengubah tampilan berdasarkan lebar **layar HP/Browser**, Container Queries mengubah tampilan berdasarkan lebar **induk pembungkusnya (Parent Container)**.

/* 1. Deklarasikan kontainer pembungkus */
.card-wrapper {
  container-type: inline-size;
}

/* 2. Berikan rule berdasarkan lebar kontainer pembungkus */
@container (min-width: 400px) {
  .card-content {
    display: flex;
    flex-direction: row;
  }
}
Mengapa Ini Penting? Komponen kartu (Card UI) kini dapat diletakkan di sidebar yang sempit maupun di area konten utama yang luas, dan kartu tersebut akan beradaptasi secara otomatis tanpa bergantung pada lebar viewport layar.

2.6 Metode BEM & Clean Architecture

BEM (Block Element Modifier) adalah standar penamaan class CSS agar struktur kode tetap rapi, mudah dirawat, dan tidak saling berbenturan (*CSS specificity collisions*) pada proyek skala besar.

/* Penulisan BEM: Block__Element--Modifier */

/* Block: Komponen Utama */
.card {}

/* Element: Bagian terikat di dalam Block */
.card__title {}
.card__button {}

/* Modifier: Variasi gaya dari Element/Block */
.card__button--danger { background: red; }
.card__button--success { background: green; }

🎯 Latihan Praktikum Industry-Grade

Buatlah file stylesheet modular bernama theme-dashboard.css dengan ketentuan berikut:

  1. Deklarasikan variabel warna di :root untuk skema warna terang dan gelap.
  2. Buat tata letak grid kartu menggunakan CSS Grid repeat(auto-fit, minmax(...)).
  3. Gunakan fungsi clamp() untuk mengatur ukuran teks judul utama dashboard.
  4. Terapkan metode penamaan class berbasis BEM Architecture pada komponen kartu dan tombol.
  5. Tambahkan kartu promo dengan efek Glassmorphism.
