Modul 01: HTML5

1. Berapa jumlah tag <main> yang diperbolehkan dalam sebuah halaman web?

Berdasarkan standar dokumen semantik W3C.

Penjelasan: Tag <main> merepresentasikan konten utama dokumen yang unik, sehingga standar HTML5 menetapkan hanya boleh ada 1 tag main per halaman.
Modul 01: HTML5

2. Atribut apa yang digunakan untuk menyembunyikan ikon dekoratif murni dari Screen Reader?

Agar screen reader tidak membacakan elemen visual yang tidak informatif.

Penjelasan: aria-hidden="true" memberi tahu screen reader untuk mengabaikan elemen dekoratif tanpa mengganggu tampilannya di layar pengguna normal.
Modul 02: CSS3

3. Apa fungsi fungsi CSS clamp(MIN, PREFERRED, MAX)?

Dalam arsitektur Fluid Typography modern.

Penjelasan: clamp() mengambil 3 parameter (min, preferred, max) untuk memastikan nilai responsif tidak pernah lebih kecil dari min atau lebih besar dari max.
Modul 02: CSS3

4. Dalam metodologi BEM, bagaimana cara penulisan elemen dan modifier yang benar?

Block Element Modifier standard.

Penjelasan: BEM membedakan Element dengan dua garis bawah (__) dan Modifier dengan dua tanda minus (--).
Modul 03: JavaScript

5. Mengapa teknik Event Delegation lebih hemat memori dibanding memasang listener di setiap tombol?

Arsitektur DOM event efisien.

Penjelasan: Event bubbling meneruskan klik elemen anak ke atas menuju parent, sehingga kita cukup memasang 1 listener di parent untuk mengawasi ribuan anak.
Modul 03: JavaScript

6. Bagaimana cara menyimpan objek JavaScript kompleks ke dalam localStorage?

Web Storage API persistence.

Penjelasan: localStorage hanya menerima string. Jika objek langsung disimpan tanpa JSON.stringify(), nilainya akan berubah menjadi teks "[object Object]" yang rusak.
