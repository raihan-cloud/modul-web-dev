3.2 Syntax Modern (Shorthand ES6+)

Tulis kode yang ringkas, ekspresif, dan minim boilerplate dengan fitur sintaksis ES6+ standar industri.

Sejak standardisasi ECMAScript 2015 (ES6), JavaScript telah bertransformasi menjadi bahasa pemrograman yang sangat ekspresif. Fitur shorthand modern menghilangkan kode berulang (*boilerplate*) dan membuat logika aplikasi lebih intuitif untuk dibaca.

1. Arrow Function & Template Literals

Arrow function memberikan sintaks fungsi yang bersih tanpa perlu kata kunci function atau return eksplisit pada pernyataan sebaris. Template Literals (menggunakan backtick `) mempermudah interpolasi variabel string tanpa konkatenasi +.

JavaScript 
// Arrow function dengan default parameter
const sapaUser = (nama, role = 'Developer') => {
  return `Halo ${nama}, status akses Anda saat ini adalah: ${role}.`;
};

console.log(sapaUser('Raihan'));
// Output: "Halo Raihan, status akses Anda saat ini adalah: Developer."

2. Destructuring Object & Array

Mengekstrak nilai properti dari objek atau elemen array langsung ke variabel individu secara ekspresif:

JavaScript 
// Destructuring Object
const userConfig = {
  theme: 'dark',
  fontSize: '16px',
  notifications: true
};

const { theme, fontSize } = userConfig;
console.log(theme); // "dark"

// Destructuring Array
const koordinat = [107.6098, -6.9175];
const [longitude, latitude] = koordinat;

3. Spread & Rest Operator (`...`)

JavaScript 
// Menggabungkan objek tanpa mengubah objek asli (Immutability)
const defaultSettings = { theme: 'light', sound: true };
const userSettings = { ...defaultSettings, theme: 'dark' };

console.log(userSettings); // { theme: 'dark', sound: true }
