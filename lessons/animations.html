2.4 CSS Animations & Glassmorphism UI

Menciptakan antarmuka berbahan efek kaca transparan menggunakan backdrop-filter dan animasi mulus 60 FPS.

Tren desain modern seperti Glassmorphism mengandalkan ilusi kedalaman visual dan materi kaca tembus pandang. Fitur ini diwujudkan menggunakan backdrop-filter: blur(), warna latar belakang semi-transparan (RGBA/HSLA), dan garis batas halus (subtle border).

Struktur Kode Glassmorphism

CSS — Glassmorphic Card 
.card-glass {
  background: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px); /* Safari iOS support */
  border: 1px solid rgba(255, 255, 255, 0.4);
  border-radius: 12px;
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.15);
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.card-glass:hover {
  transform: translateY(-4px);
}

Efek Kaca Transparan Native

Komponen ini memburamkan elemen di balik permukaannya menggunakan backdrop-filter langsung di level browser tanpa render gambar raster tambahan.

⚡ Aturan Kinerja Animasi: Hanya Animasikan `transform` & `opacity`

Hindari membuat transisi animasi pada properti width, height, top, atau margin. Properti tersebut memicu perhitungan layout (Reflow) yang berat pada CPU. Gunakan transform: translate() dan opacity yang diproses langsung oleh GPU untuk menjamin mulus 60 FPS.
