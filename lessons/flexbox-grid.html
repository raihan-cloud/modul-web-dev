2.2 Flexbox vs CSS Grid Mastery

Kapan harus menggunakan Flexbox dan kapan harus memilih CSS Grid? Simak panduan spasial 1D vs 2D dan trik grid responsif tanpa media query.

Yang Akan Anda Pelajari:
  • ✓ Perbedaan fundamental 1-Dimensi (Flexbox) vs 2-Dimensi (Grid)
  • ✓ Pola auto-fit repeat(auto-fit, minmax(130px, 1fr)) tanpa @media
  • ✓ Perbedaan auto-fit vs auto-fill
  • ✓ Kombinasi Grid untuk halaman dan Flexbox untuk komponen

Pahami perbedaan mendasar arsitektur tata letak modern:

  • Flexbox (1-Dimensi): Dirancang khusus untuk komponen linear baris ATAU kolom (misal: navigasi navbar, badge grup, card actions, form inline).
  • CSS Grid (2-Dimensi): Dirancang khusus untuk tata letak matriks baris DAN kolom secara simultan (misal: dashboard widget grid, gallery foto, layout artikel multi-kolom).

Pola Responsive Grid Modern Tanpa Media Queries (`auto-fit`)

Dengan mengombinasikan fungsi repeat(), auto-fit, dan minmax(), kita dapat membuat tata letak kolom yang otomatis melipat ke bawah saat layar menyempit tanpa menulis satu baris pun @media rule:

CSS — Auto-Fit Responsive Grid 
/* Kolom otomatis menyesuaikan lebar layar tanpa @media queries */
.dashboard-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(130px, 1fr));
  gap: 1rem;
}

💡 Perbedaan `auto-fit` vs `auto-fill`

auto-fill akan tetap membuat slot kolom kosong jika ruang masih tersedia di layar lebar. Sebaliknya, auto-fit akan meregangkan item yang ada untuk mengisi seluruh ruang horizontal yang tersisa (1fr), sehingga layout tidak menyisakan rongga kosong yang aneh.

Quick Check (+50 XP) Uji Pemahaman

Trik CSS Grid apa yang membuat kolom otomatis responsif melipat ke bawah tanpa @media query?

Penjelasan: Kombinasi repeat(auto-fit, minmax(...)) menghitung kapasitas kolom secara dinamis sesuai lebar layar.
