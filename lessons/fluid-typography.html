2.3 Fluid Typography dengan `clamp()`

Tinggalkan breakpoint manual untuk font. Gunakan fungsi matematika clamp() untuk tipografi yang beradaptasi halus di semua layar.

Yang Akan Anda Pelajari:
  • ✓ Formula matematika CSS clamp(MIN, VAL, MAX)
  • ✓ Mencegah font terlalu raksasa atau terlalu kerdil
  • ✓ Aksesibilitas zoom browser dengan menggabungkan rem + vw
  • ✓ Skala tipografi fluid dalam variabel desain

Fungsi matematika CSS clamp(MIN, PREFERRED, MAX) menetapkan nilai ideal yang dinamis, namun menguncinya di antara batas bawah (minimum) dan batas atas (maksimum). Ini memungkinkan ukuran teks membesar dan mengecil secara halus seiring perubahan lebar viewport monitor tanpa perlu menulis banyak baris breakpoint @media query.

Struktur Formula `clamp()`

CSS — Fluid clamp() Formula 
h1 {
  /* Nilai Min: 1.5rem (24px)
     Nilai Ideal: 4vw (4% lebar layar)
     Nilai Max: 3rem (48px) */
  font-size: clamp(1.5rem, 4vw, 3rem);
  line-height: 1.2;
}

/* Penerapan pada skala variabel global */
:root {
  --text-fluid-title: clamp(1.75rem, 3vw + 1rem, 2.75rem);
}

💡 Accessibility Tips: Gabungkan `vw` dengan `rem`

Jika Anda hanya menggunakan nilai 4vw murni tanpa satuan rem, pembesaran teks browser pengguna (fitur zoom disabilitas WCAG) tidak akan berfungsi optimal. Selalu campur unit viewport dengan rem, misalnya: clamp(1.5rem, 2.5vw + 0.5rem, 2.75rem).

Quick Check (+50 XP) Uji Pemahaman

Apa parameter kedua pada fungsi clamp(1rem, 3vw, 2.5rem)?

Penjelasan: Parameter kedua adalah nilai ideal/preferred yang akan aktif selama berada di antara nilai min dan max.
