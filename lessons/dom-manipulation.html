3.3 DOM Selection & Class Manipulation

Pisahkan logika perilaku dengan presentasi visual. Kelola state tampilan dengan memanipulasi CSS class, bukan inline style.

Yang Akan Anda Pelajari:
  • ✓ Seleksi elemen dengan querySelector dan querySelectorAll
  • ✓ Metode classList.add(), remove(), toggle(), contains()
  • ✓ Alasan menghindari manipulasi inline element.style.*
  • ✓ Pemisahan tanggung jawab (Separation of Concerns)

Alih-alih mengubah properti element.style.color atau element.style.display secara langsung (inline style), arsitektur web modern menganjurkan pemisahan tanggung jawab (*Separation of Concerns*): CSS mengatur tampilan visual lewat class, dan JavaScript hanya bertugas menambah, menghapus, atau mengganti class tersebut menggunakan classList API.

Penggunaan `classList.toggle()`

JavaScript 
const cardElement = document.querySelector('.card-target');
const btnToggle = document.querySelector('#btn-toggle');

btnToggle.addEventListener('click', () => {
  // Menambahkan class jika belum ada, menghapusnya jika sudah ada
  const isActive = cardElement.classList.toggle('card-target--active');
  console.log(`Status aktif: ${isActive}`);
});

⚠️ Mengapa Inline Style Buruk Bagi Arsitektur?

Mengubah element.style.* memiliki spesifisitas CSS tertinggi (1,0,0,0) yang menimpa aturan stylesheet biasa, menyulitkan Dark Mode otomatis, dan memicu kalkulasi ulang gaya secara berlebihan (*style recalculation repaint*).

Quick Check (+50 XP) Uji Pemahaman

Metode classList apa yang otomatis menambah class jika belum ada dan menghapusnya jika sudah ada?

Penjelasan: classList.toggle() membalik status keberadaan class secara efisien dalam 1 baris kode.
