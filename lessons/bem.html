2.6 Metode BEM & Clean Architecture

Block Element Modifier (BEM) adalah standar industri untuk penulisan CSS rapi, mudah dipelihara, dan bebas dari konflik specificity.

Yang Akan Anda Pelajari:
  • ✓ Struktur penamaan .block__element--modifier
  • ✓ Menghindari konflik spesifisitas CSS pada skala besar
  • ✓ Pengelolaan file stylesheet modular per komponen
  • ✓ Praktek refactoring kode legacy menjadi arsitektur BEM

BEM (Block Element Modifier) adalah standar konvensi penamaan class CSS terpopuler di industri teknologi dunia. Tujuannya adalah memastikan setiap developer dalam tim dapat membaca kode dan langsung memahami relasi antar komponen visual tanpa takut merusak bagian web yang lain (zero CSS specificity wars).

Struktur Anatomi Penamaan BEM

CSS — BEM Architecture 
/* Formula: .block__element--modifier */

/* 1. BLOCK: Komponen mandiri yang bermakna sendiri */
.btn {}
.card {}

/* 2. ELEMENT: Bagian anak yang terikat di dalam Block (dua underscore) */
.card__header {}
.card__title {}
.card__body {}
.card__action {}

/* 3. MODIFIER: Varian gaya atau status dari Block/Element (dua minus) */
.btn--primary {}
.btn--danger {}
.btn--lg {}
.card--highlighted {}

Quick Check (+50 XP) Uji Pemahaman

Simbol apa yang memisahkan nama Block dengan Element dalam metodologi BEM?

Penjelasan: BEM memisahkan Element dengan double underscore (__), sedangkan Modifier dengan double hyphen (--).
