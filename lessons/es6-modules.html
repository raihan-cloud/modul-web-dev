3.1 Loading Strategy Modern & ES6 Modules

Kuasai strategi pemuatan script non-blocking: atribut defer vs async dan modularitas type="module" bawaan browser.

Yang Akan Anda Pelajari:
  • ✓ Perbedaan script defer vs async vs default
  • ✓ Deklarasi script type="module" native browser
  • ✓ Sintaks import dan export modular
  • ✓ Pencegahan polusi variabel global di window scope

Pada era web terdahulu, developer sering menempatkan tag <script> di dasar halaman sebelum penutup </body> untuk menghindari pemblokiran parsing HTML. Pada standar web modern saat ini, kita memiliki atribut defer dan sistem ES6 Native Modules (type="module") yang dapat diletakkan rapi di dalam <head>.

Atribut `defer` vs `async` vs `type="module"`

  • defer: Mengunduh script di latar belakang (background) secara paralel tanpa menghentikan parsing HTML, dan mengeksekusinya berurutan persis setelah DOM siap dirender.
  • async: Mengunduh script secara paralel dan langsung menghentikan rendering untuk mengeksekusinya seketika setelah selesai diunduh (cocok untuk skrip analytics pihak ketiga yang tidak bergantung pada DOM).
  • type="module": Mengaktifkan import/export JavaScript murni native. Secara otomatis memiliki perilaku seperti defer dan strict mode ("use strict").
HTML — Head Script Declaration 
<head>
  <!-- Script aplikasi umum: non-blocking dengan defer -->
  <script src="app.js" defer></script>

  <!-- Modul ES6 terpisah tanpa butuh Webpack/Vite bundler -->
  <script type="module" src="main.js"></script>
</head>

Sintaks Import & Export Native di Browser

JavaScript — ES6 Modules 
// File: utils.js
export const formatCurrency = (amount) => {
  return new Intl.NumberFormat('id-ID', { style: 'currency', currency: 'IDR' }).format(amount);
};

// File: main.js
import { formatCurrency } from './utils.js';

console.log(formatCurrency(150000)); // "Rp 150.000,00"
💡 Bebas Polusi Variabel Global (Window Scope)

Dengan type="module", setiap file JS memiliki ruang lingkup (scope) privat sendiri. Variabel atau fungsi tidak akan mengotori objek global window, mencegah bug benturan nama fungsi antar library.

Quick Check (+50 XP) Uji Pemahaman

Mengapa atribut defer disarankan untuk script aplikasi yang memanipulasi DOM?

Penjelasan: defer tidak memblokir parsing HTML dan menjamin eksekusi tepat setelah pohon DOM selesai dibangun.
