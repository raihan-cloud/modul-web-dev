3.6 State Persistence via `localStorage`

Simpan status preferensi tema, progres belajar, atau keranjang belanja pengguna secara persisten di browser tanpa database backend.

Yang Akan Anda Pelajari:
  • ✓ Metode Web Storage: setItem, getItem, removeItem, clear
  • ✓ Serialisasi struktur Objek kompleks dengan JSON.stringify & JSON.parse
  • ✓ Penyimpanan persisten state lokal antar sesi browser
  • ✓ Penerapan nyata sistem Single Source of Truth progress belajar

Fitur Web Storage API (localStorage) memungkinkan penyimpanan data pasangan kunci-nilai (key-value) langsung di browser klien. Data ini bertahan selamanya bahkan setelah tab ditutup atau komputer direstart, hingga pengguna membersihkan cache peramban.

Operasi Dasar `localStorage`

JavaScript — Web Storage API 
// 1. Menyimpan data string sederhana
localStorage.setItem('theme', 'dark');

// 2. Mengambil data
const currentTheme = localStorage.getItem('theme'); // "dark"

// 3. Menyimpan Objek Kompleks menggunakan JSON serialization
const userProgress = { module1: 100, module2: 100, module3: 100 };
localStorage.setItem('progress', JSON.stringify(userProgress));

// 4. Membaca kembali Objek
const savedData = JSON.parse(localStorage.getItem('progress'));
console.log(savedData.module1); // 100

// 5. Menghapus data
localStorage.removeItem('theme');
localStorage.clear(); // Hapus semua key
