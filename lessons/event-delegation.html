3.4 Event Delegation Architecture

Teknik arsitektur event berkinerja tinggi: 1 Event Listener pada Parent untuk menangani ribuan elemen dinamis tanpa memory leaks.

Memasang ratusan addEventListener ke setiap elemen anak (seperti baris tabel atau kartu produk) adalah pola yang memboroskan RAM browser. Selain itu, elemen yang baru ditambahkan via JavaScript tidak akan otomatis memiliki event listener tersebut.

Solusinya adalah Event Delegation: Memanfaatkan fase Event Bubbling di mana klik pada elemen anak akan otomatis naik (bubble up) ke elemen induknya (Parent).

Contoh Pola Delegasi dengan `closest()`

JavaScript — Delegation Pattern 
// Hanya 1 listener terpasang pada pembungkus induk
const todoList = document.querySelector('#todo-list');

todoList.addEventListener('click', (e) => {
  // Mengecek apakah elemen yang diklik adalah tombol hapus
  const deleteBtn = e.target.closest('.btn-delete');
  if (!deleteBtn) return;

  // Mengambil baris todo terkait
  const todoItem = deleteBtn.closest('.todo-item');
  if (todoItem) {
    todoItem.remove(); // Hapus dari DOM
  }
});

✅ Keuntungan Utama Event Delegation

1. Hemat Memori: Mengurangi alokasi memory heap di browser secara drastis.
2. Dukungan Dinamis 100%: Elemen yang baru ditambahkan detik ini langsung memiliki fungsi hapus/klik tanpa perlu mendaftarkan listener ulang.
