2.5 Container Queries (`@container`)

Paradigma baru responsive design: komponen yang mengubah tata letaknya sendiri berdasarkan ukuran wadah induknya, bukan layar browser.

Teknik responsif masa depan telah tiba di browser modern: Jika Media Queries mengubah tampilan berdasarkan lebar viewport layar browser/HP, Container Queries mengubah tampilan berdasarkan lebar elemen pembungkusnya (Parent Container).

2 Langkah Mendeklarasikan Container Query

CSS — Container Queries Syntax 
/* 1. Daftarkan elemen induk sebagai container */
.card-wrapper {
  container-type: inline-size;
  container-name: product-widget; /* opsional */
}

/* 2. Berikan aturan tampilan saat wadah induknya >= 450px */
@container (min-width: 450px) {
  .card-content {
    display: flex;
    flex-direction: row;
    align-items: center;
  }
}

Komponen Modular Mandiri

Jika container sempit (< 450px), kartu ini menumpuk secara vertikal. Jika container melebar, kartu otomatis menyusun elemen secara horizontal!

💡 Mengapa Ini Sangat Penting Bagi Desain Sistem Modern?

Komponen UI (seperti Product Card atau Comment Widget) kini dapat diletakkan di dalam Sidebar yang sempit (300px) maupun di area Konten Utama yang luas (800px), dan kartu tersebut akan beradaptasi secara cerdas tanpa perlu class modifier terpisah (seperti .card--compact).
