1.6 Data Attributes (`data-*`) & Custom State

HTML5 memperbolehkan kita membuat atribut data kustom untuk menyimpan state DOM yang mudah diakses CSS dan JavaScript.

HTML5 memperbolehkan developer membuat atribut kustom asalkan diawali dengan kata data-. Teknik ini sangat lazim di dunia industri untuk menyimpan data "tersembunyi" di dalam tag HTML tanpa mengacaukan struktur semantik dokumen, yang nantinya dapat diproses oleh styling CSS maupun logika JavaScript.

1. Menyimpan State di Markup HTML

HTML 
<!-- Menyimpan status ketersediaan barang dan ID database -->
<div class="product-card" data-product-id="A883" data-stock="habis">
  <h3>Sepatu Sneaker Pro Runner</h3>
  <p>Rp 899.000</p>
</div>

2. Styling dengan CSS Attribute Selector

CSS 
/* Mengubah styling otomatis saat status data-stock bernilai "habis" */
.product-card[data-stock="habis"] {
  opacity: 0.6;
  filter: grayscale(80%);
  pointer-events: none; /* Menonaktifkan klik */
}

/* Menambahkan label tanda habis menggunakan pseudo-element */
.product-card[data-stock="habis"]::after {
  content: " STOK HABIS";
  display: inline-block;
  color: var(--color-danger);
  font-weight: bold;
}

3. Akses via JavaScript Object `dataset`

Browser otomatis mengubah format nama kebab-case menjadi camelCase di dalam properti element.dataset:

JavaScript 
const card = document.querySelector('.product-card');

// "data-product-id" otomatis menjadi card.dataset.productId
console.log(card.dataset.productId); // "A883"
console.log(card.dataset.stock);     // "habis"

// Mengubah status secara dinamis lewat JS:
card.dataset.stock = "tersedia";
