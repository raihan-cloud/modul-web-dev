1.3 Form & Validasi Bawaan Lanjutan

Manfaatkan kekuatan engine validasi native HTML5 untuk formulir yang aman, cepat, dan bekerja tanpa dependensi library JavaScript berat.

HTML5 dilengkapi mesin validasi data terintegrasi langsung di level browser. Anda tidak perlu mengimpor library validator JavaScript berukuran besar hanya untuk mengecek field wajib diisi, format email, batasan panjang teks, atau pencocokan pola regex.

Atribut Validasi Penting

  • required: Menandai kolom wajib diisi sebelum form dapat disubmit.
  • pattern="[regex]": Menguji input teks terhadap aturan Regular Expression (misal: tepat 6 digit PIN, format nomor telepon, atau karakter tertentu).
  • minlength & maxlength: Membatasi panjang karakter minimum dan maksimum yang diizinkan.
  • <datalist>: Memberikan saran auto-complete otomatis saat user mengetik, namun tetap mengizinkan input fleksibel.

💡 Tips UI/UX Modern: Pseudo-class `:valid` dan `:invalid`

Pada form demo di atas, CSS pseudo-class :focus:valid dan :focus:invalid:not(:placeholder-shown) digunakan untuk memberi indikator border hijau atau merah secara instan saat pengguna mengetik, memberikan umpan balik visual yang menyenangkan (feedback loop).

Contoh Kode Markup Form

HTML — Native Validation Snippet 
<form action="/api/submit" method="POST">
  <!-- Validasi Email Native -->
  <label for="user-email">Alamat Email</label>
  <input type="email" id="user-email" required placeholder="user@domain.com">

  <!-- Validasi Pola Regex (6 Angka) -->
  <label for="user-pin">PIN 6 Digit</label>
  <input type="text" id="user-pin" pattern="\d{6}" maxlength="6" required title="Masukkan 6 angka">

  <!-- Autocomplete dari list -->
  <input list="cities" id="city-input" placeholder="Pilih kota...">
  <datalist id="cities">
    <option value="Jakarta">
    <option value="Surabaya">
    <option value="Bandung">
  </datalist>

  <button type="submit">Kirim Data</button>
</form>
