1.5 Open Graph & Social Meta Tags

Kustomisasi tampilan URL website Anda saat dibagikan di WhatsApp, LinkedIn, Discord, Telegram, dan Twitter/X.

Yang Akan Anda Pelajari:
  • ✓ Protokol metadata Open Graph (og:title, og:image, og:description)
  • ✓ Twitter Card tags (summary_large_image)
  • ✓ Pengaturan theme-color status bar mobile
  • ✓ Standar rasio gambar cover media sosial (1200 x 630 px)

Pernahkah Anda menempelkan URL di WhatsApp, LinkedIn, atau Twitter/X, dan seketika muncul kartu pratinjau yang indah berisi thumbnail cover, judul rapi, dan deskripsi singkat? Efek tersebut dikendalikan oleh protokol metadata Open Graph (OG) dan Twitter Cards yang dideklarasikan di dalam tag <head> dokumen HTML.

Anatomi Meta Tags Wajib

  • og:title: Judul halaman saat ditampilkan sebagai kartu sharing.
  • og:description: Rangkuman satu atau dua kalimat yang menarik pembaca untuk mengklik.
  • og:image: URL mutlak gambar sampul (resolusi standar industri: 1200 x 630 piksel).
  • og:url: Alamat kanonikal permanen dari tautan tersebut.
  • twitter:card: Tipe kartu pada platform Twitter/X, biasanya summary_large_image untuk visual besar.
  • theme-color: Warna bilah status browser di perangkat mobile (Chrome Android/Safari iOS).
HTML — Head Metadata Snippet 
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Penyesuaian Warna Status Bar Mobile -->
  <meta name="theme-color" content="#2563eb">

  <!-- Meta Standar SEO -->
  <title>Portofolio Web Developer | Raihan</title>
  <meta name="description" content="Koleksi proyek frontend modern dengan arsitektur bersih dan performa tinggi.">

  <!-- Open Graph (WhatsApp, LinkedIn, Facebook, Slack) -->
  <meta property="og:type" content="website">
  <meta property="og:url" content="https://portofoliokamu.com/">
  <meta property="og:title" content="Portofolio Web Developer | Raihan">
  <meta property="og:description" content="Koleksi proyek frontend modern dengan arsitektur bersih dan performa tinggi.">
  <meta property="og:image" content="https://portofoliokamu.com/assets/og-cover.jpg">

  <!-- Twitter / X Card -->
  <meta name="twitter:card" content="summary_large_image">
  <meta name="twitter:title" content="Portofolio Web Developer | Raihan">
  <meta name="twitter:description" content="Koleksi proyek frontend modern dengan arsitektur bersih.">
  <meta name="twitter:image" content="https://portofoliokamu.com/assets/og-cover.jpg">
</head>
⚠️ URL Gambar Harus Bersifat Mutlak (Absolute URL)

Crawler sosial media seperti WhatsApp dan Facebook scraper tidak dapat memecahkan path relatif seperti assets/og-cover.jpg. Selalu sertakan domain lengkap protokol https://... pada atribut og:image.

Quick Check (+50 XP) Uji Pemahaman

Berapa ukuran resolusi gambar cover rekomendasi standar industri untuk og:image?

Penjelasan: 1200 x 630 px adalah standar rasio emas 1.91:1 yang menghasilkan tampilan tajam di WhatsApp, LinkedIn, dan Twitter.
