1.4 Optimasi Media & Mencegah CLS (Core Web Vitals)

Gambar adalah penyumbang bandwidth terbesar di web. Pelajari strategi Core Web Vitals untuk rendering cepat tanpa pergeseran layout.

Google memberi nilai peringkat SEO lebih tinggi pada website yang memuat dengan cepat dan stabil. Gambar adalah penyumbang ukuran payload bandwidth terbesar. Jika gambar dimuat terlambat tanpa alokasi ukuran yang pas, teks dan tombol akan melompat-lompat ke bawah (dikenal sebagai Cumulative Layout Shift / CLS), yang merusak pengalaman pengguna.

3 Aturan Emas Optimasi Gambar

  1. Selalu definisikan atribut width dan height: Memberikan rasio aspek pada browser sehingga ruang kosong sudah dipesan sebelum file gambar selesai di-download. Ini menghilangkan lonjakan CLS secara 100%.
  2. Gunakan Format Modern (AVIF & WebP): Format AVIF dan WebP menghasilkan kompresi hingga 50-70% lebih kecil dibandingkan JPG atau PNG tradisional dengan ketajaman visual serupa.
  3. Native Lazy Loading: Tambahkan atribut loading="lazy" agar gambar di bawah lipatan layar (below-the-fold) tidak didownload sebelum pengguna menggulir mendekatinya.

Penggunaan Tag <picture> untuk Responsive Art Direction

Tag <picture> memungkinkan kita menyajikan format file tercanggih yang didukung oleh browser pengguna, dengan fallback yang aman ke JPG/PNG jika browser lawas digunakan:

HTML — Responsive Picture Pattern 
<!-- Browser membaca dari atas ke bawah -->
<!-- Jika mendukung AVIF, pakai AVIF. Jika tidak, coba WebP. Terakhir: JPG -->
<picture>
  <source srcset="banner-promo.avif" type="image/avif">
  <source srcset="banner-promo.webp" type="image/webp">
  <img 
    src="banner-promo.jpg" 
    alt="Promo diskon akhir tahun 50% untuk kursus web development" 
    width="1200" 
    height="600" 
    loading="lazy"
    decoding="async">
</picture>
💡 Apa itu decoding="async"?

Atribut decoding="async" mengizinkan browser memproses dekode gambar di luar alur utama (off the main thread), sehingga thread rendering UI tidak tersendat (jank-free scrolling).
