2.1 CSS Variables & Dark Mode System

Kelola palet warna terpusat dan bangun fitur Dark Mode profesional hanya dalam beberapa baris CSS deklaratif.

Penggunaan CSS Custom Properties (CSS Variables) memungkinkan pengelolaan sistem desain terpusat, mempermudah rebranding instan, dan pembuatan fitur Mode Gelap (Dark Mode) berkinerja tinggi tanpa kompilasi build-step tambahan.

Deklarasi Token pada Pseudo-Class :root

Variabel CSS dideklarasikan dengan awalan tanda minus ganda (--) di dalam selector :root sehingga dapat diakses oleh seluruh elemen anak dalam dokumen:

CSS — Design Tokens & Dark Mode 
:root {
  --bg-primary: #ffffff;
  --text-primary: #0f172a;
  --text-secondary: #64748b;
  --brand-color: #2563eb;
  --border-color: #e2e8f0;
}

/* 1. Otomatis mengikuti preferensi OS pengguna */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #0f172a;
    --text-primary: #f8fafc;
    --text-secondary: #94a3b8;
    --border-color: #334155;
  }
}

/* 2. Manual toggle override menggunakan atribut [data-theme] */
[data-theme="dark"] {
  --bg-primary: #0f172a;
  --text-primary: #f8fafc;
  --text-secondary: #94a3b8;
  --border-color: #334155;
}

/* Penerapan variabel pada komponen */
body {
  background-color: var(--bg-primary);
  color: var(--text-primary);
}
💡 Keunggulan CSS Variables Dibanding Variabel SASS / SCSS

Variabel CSS bersifat dinamis di runtime dan mewariskan nilainya ke elemen turunan (cascading). Anda dapat mengubah variabel tertentu secara lokal di satu komponen saja, atau memodifikasinya secara real-time via JavaScript (element.style.setProperty('--color', val)), yang tidak bisa dilakukan pada preprocessor statis seperti SASS setelah di-compile.
